# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom
- **Notes:** A referência é a `docs/SPEC.md`, seção 6: tokens tricolores (azul `--primary`, branco, vermelho `--accent`) em `src/styles.css`, Fjalla One nos títulos, IBM Plex Sans no corpo e IBM Plex Mono em números, largura máxima de 1152 px, tema claro e escuro. Não aproximar o site do visual de outro produto. Nada da identidade visual da empresa (regra 4 do `CLAUDE.md`).
- **Padrão de página de `/castelo`:** fora do catálogo de `page-patterns`, por decisão registrada na SPEC 9. É uma página de jogo: título, canvas, legenda e controles. Não usar como modelo para outras páginas.
- **Modo Castelo (SPEC 9):** dentro do canvas vale pixel art 16-bit em base escura, com as cores tricolores só no que está restaurado. Tudo que é HTML em volta ou por cima do canvas (pergaminho, controles, textos) segue esta identidade, não a do jogo.

## Banned anti-aesthetics

- Glassmorphism ou `backdrop-filter` sem uma borda de contraste
- Badges pastel flutuantes para metadado comum
- Gradientes decorativos arbitrários e bordas neon brilhantes
- Gradiente radial multicolorido em botões de ação
- Ilustrações cartunescas em estados vazios (pessoas acenando, comemorando)
- Barras de rolagem aninhadas e excesso de ícones dentro de campos

Exceções permitidas, por já estarem na SPEC 6.1. Qualquer efeito novo fora delas é proibido:

1. O cabeçalho translúcido (`glass`), sempre com `border-b border-border`.
2. O `--gradient-primary` (azul para vermelho) no nome do hero, no item ativo do menu e nos botões principais. Nenhum outro gradiente.
3. Os chips de domínio e de status com fundo suave, desde que tragam ícone e rótulo escrito. A cor nunca é o único sinal.

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4,5:1 em texto normal; 3:1 em texto grande, bordas e ícones com função. Vale nos dois temas e em todos os pares da SPEC 6.1.
- **Touch / focus:** alvos de toque de pelo menos 44x44 px, anel de foco visível em todo elemento interativo. No castelo: pergaminho com foco preso e Esc para fechar, e nenhum movimento decorativo com `prefers-reduced-motion` (SPEC 9.4).

## Brand tone and microcopy voice

- **Voice:** Opinionated & Direct
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** PT-BR, primeira pessoa, frases curtas, verbo na frente, fato concreto no lugar de adjetivo. Sem travessão em texto visível: usar vírgula, dois-pontos ou ponto. No castelo cabe uma frase de ambiente por tela, sem narração longa. Nenhum dado interno da empresa (regras de conteúdo do `CLAUDE.md`).

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react` (já em `package.json`)
- **Notes:** Único conjunto para a interface HTML. Os sprites de pixel art dentro do canvas do castelo são arte do jogo, não ícones de interface.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
